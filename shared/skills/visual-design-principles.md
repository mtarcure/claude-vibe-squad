# Visual Design Principles

Apply the core principles — hierarchy, contrast, alignment, repetition, proximity, balance — to make a design legible and intentional.

## Steps
1. Establish visual hierarchy: rank what the viewer should notice first, second, third, and make size/weight/color serve that rank.
2. Use contrast to separate levels and alignment to create order; nothing sits by accident.
3. Apply repetition/consistency so related elements share a visual language (spacing scale, type scale, component style).
4. Use proximity to group what belongs together and space to separate what doesn't.
5. Reconcile against accessibility and brand constraints; cross-check color decisions with `color-theory` and layout with `composition-rules`.

## Acceptance
- A deliberate hierarchy is present and defensible (why this reads first).
- Alignment, spacing, and type follow a consistent scale, not one-offs.
- The design respects stated brand and accessibility constraints.
