# Voice Performance Direction

Direct a voice performance (human or synthesized) — intent, delivery, and consistency — so the read serves the script.

## Steps
1. Define the character/brand voice, intent, and emotional target for the read before generation/recording.
2. Mark the script for delivery: emphasis, pace, pauses, tone shifts, and pronunciation of tricky terms.
3. Direct in passes (intent → energy → nuance); give specific, actionable notes, not "do it better."
4. Keep continuity across takes/sessions so the performance is consistent.
5. Respect likeness/consent: never direct a synthesized clone of a real person's voice without cleared consent; flag for `rule6-rights-gate`.

## Acceptance
- Intent, emotional target, and a marked-up script exist before the read.
- Direction notes are specific and actionable; performance is consistent across takes.
- Voice-likeness consent is verified, never self-cleared.
