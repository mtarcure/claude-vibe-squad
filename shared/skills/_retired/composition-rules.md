# Composition Rules

Arrange elements in a frame so the eye lands where intended: focal point, balance, and flow by rule, not accident.

## Steps
1. Name the single focal point and the reading path the viewer should follow.
2. Place elements against an explicit structure (grid, rule-of-thirds, golden ratio, symmetry/asymmetry) that serves that path.
3. Control visual weight and balance so nothing competes with the focal point unintentionally.
4. Use whitespace, alignment, and grouping (proximity) to build hierarchy; check the layout at target crop/aspect ratios.
5. Verify the composition holds at the delivery size and on the busiest real content, not just the ideal mock.

## Acceptance
- The focal point and intended reading path are stated and visually achieved.
- Layout sits on an explicit structure; balance is intentional.
- The composition survives real content and the target aspect ratio/crop.
